# موتور قیمت خودرو لامرد خودرو (Price Engine)

افزونه: `lamerd-khodro-price-engine` — نام نمایشی: «مدیریت قیمت خودرو».

## ۱. منبع داده

`CafeKhodroProvider` از دو Endpoint عمومی استفاده می‌کند:

| کاربرد | مسیر |
|---|---|
| فهرست جدول‌ها | `https://cofekhodro.ir/wp-json/cafekhodro/v1/tables` |
| داده جدول | `https://cofekhodro.ir/wp-json/cafekhodro/v1/tables/1` |

ساختار واقعی بررسی‌شده (آبان ۱۴۰۵):

```json
{
  "id": 1, "title": "لیست قیمت های خودرو داخلی", "unit": "toman",
  "updated_at": "2026-11-02T09:10:28+00:00", "count": 115,
  "cars": [{
    "id": 2, "group": "ایران خودرو", "name": "سورن XU7P برقی",
    "factory_price": 1725606700, "market_price": 2500000000,
    "production_stopped": false,
    "change": { "amount": -20000000, "percent": -0.79 }
  }]
}
```

نکات واقعی داده که کد برای آن‌ها نوشته شده است:

- `factory_price` در حدود ۲۳ رکورد `null` است.
- `market_price` در چند رکورد `null` است.
- `change` در حدود ۲۱ رکورد `null` است.
- مقدار `0` در قیمت معادل «ناموجود» در نظر گرفته می‌شود، نه صفر تومان.
- رکوردهای ناسازگار در خود منبع دیده می‌شود (مثلاً تغییر `-99.9%` یا تغییر بزرگ‌تر از قیمت). این‌ها `suspect` علامت می‌خورند و مقدار تغییرشان نمایش داده نمی‌شود.

## ۲. شرایط استفاده از منبع

- بدون API Key.
- محدودیت ۱۲۰ درخواست در دقیقه برای هر IP. همگام‌سازی هر بار فقط ۲ درخواست می‌زند و شمارنده داخلی قبل از عبور از آستانه توقف می‌کند.
- درج نام منبع و لینک الزامی است: «منبع: کافه خودرو — https://cofekhodro.ir» در صفحه قیمت، جزئیات خودرو و گزارش‌ها نمایش داده می‌شود.
- User-Agent شناسنامه‌دار: `LamerdKhodroPriceEngine/1.0 (+https://lamerdkhodro.ir)`.

## ۳. خط لوله همگام‌سازی

```
قفل عملیات ─► ثبت رکورد لاگ (running) ─► دریافت جدول ─► اعتبارسنجی پاسخ
   ─► برای هر خودرو: نرمال‌سازی ─► upsert خودرو ─► اتصال به CPT
   ─► مقایسه قیمت ─► تاریخچه (در صورت تغییر) ─► به‌روزرسانی قیمت جاری
   ─► Snapshot روزانه ─► پایان لاگ ─► آزادسازی قفل
```

- **قفل:** `lkpe_sync_lock` با توکن و انقضای ۱۵ دقیقه. عملیات هم‌زمان دوم با پیام «همگام‌سازی در حال اجراست» رد می‌شود. قفل رهاشده پس از انقضا خودکار آزاد می‌شود.
- **Retry:** حداکثر ۳ تلاش با تأخیر افزایشی ۲، ۵ و ۱۰ ثانیه برای `429`، `5xx`، Timeout و خطای شبکه. هدر `Retry-After` رعایت می‌شود.
- **اتمی بودن:** هر خودرو مستقل پردازش می‌شود؛ خطای یک رکورد باعث حذف داده‌های قبلی یا توقف کل عملیات نمی‌شود و در `errors_count` ثبت می‌گردد.
- **بدون داده ساختگی:** تا زمانی که دریافت واقعی انجام نشود، هیچ قیمتی در دیتابیس نیست.

## ۴. قواعد ثبت تاریخچه

| رخداد | رکورد تاریخچه |
|---|---|
| نخستین دریافت خودرو | `record_type = initial` |
| تغییر قیمت بازار | `market_change` |
| تغییر قیمت کارخانه | `factory_change` |
| بدون تغییر | ثبت نمی‌شود؛ فقط `fetched_at` به‌روز می‌شود |
| Snapshot روزانه | یک رکورد در `lkp_price_snapshots` برای هر خودرو در هر روز |

- زمان دریافت (`recorded_at` / `fetched_at`) با زمان اعلام منبع (`declared_at`) جدا نگه داشته می‌شود.
- تاریخچه هرگز حذف یا بازنویسی نمی‌شود.
- قیمت ناموجود باعث صفر شدن قیمت قبلی نمی‌شود؛ قیمت `null` در قیمت جاری ثبت می‌شود اما در نمودار به‌صورت شکاف نمایش داده می‌شود.

## ۵. زمان‌بندی

- WP-Cron با رویداد `lkpe_sync_event` و بازه‌های ۱۵ دقیقه، ۳۰ دقیقه، ۱ ساعت، ۳ ساعت، روزانه. پیش‌فرض: ۶۰ دقیقه.
- تغییر بازه در تنظیمات، رویداد را فوراً باززمان‌بندی می‌کند.
- امکان زمان‌بندی واقعی هاست: در صفحه «همگام‌سازی» دستور نمونه نمایش داده می‌شود:

```
*/15 * * * * cd /path/to/wordpress && php wp-cli.phar lkpe sync --quiet
```

- اجرای دستی از پیشخوان و از CLI (`wp lkpe sync`) پشتیبانی می‌شود.
- همگام‌سازی دستی هرگز بیش از یک بار هم‌زمان اجرا نمی‌شود.

## ۶. اعتبارسنجی

| قاعده | نتیجه نقض |
|---|---|
| شناسه عددی مثبت و نام غیرخالی | رد رکورد و ثبت خطا |
| قیمت عدد صحیح مثبت یا `null` | `0` → `null` |
| قیمت بازار موجود باشد | `data_status = incomplete` |
| `|change.percent| ≤ 100` و `|change.amount| ≤ 2×market` | `data_status = suspect`، تغییر نمایش داده نمی‌شود |
| گروه/برند قابل تشخیص | برند «سایر» با نگاشت واژگانی |

## ۷. استقلال از API

- نمایش، گزارش و نمودار فقط از دیتابیس داخلی می‌خوانند.
- هنگام قطع API، آخرین رکورد معتبر حفظ می‌شود و `is_stale` بر اساس بازه تنظیم‌شده (۲ برابر فاصله همگام‌سازی، حداقل ۳ ساعت) محاسبه می‌شود.
- صفحه قیمت «آخرین به‌روزرسانی موفق» و هشدار کهنگی را نشان می‌دهد؛ هیچ درخواست سمت کاربر به دامنه خارجی زده نمی‌شود.

## ۸. گزارش و خروجی

- گزارش‌های روزانه/هفتگی/ماهانه/سالانه، بیشترین افزایش/کاهش، میانگین تغییر، اختلاف بازار و کارخانه، مقایسه برندها، خودروهای بدون تغییر، عملکرد منابع و تعداد دریافت موفق/ناموفق.
- خروجی CSV با BOM، XLSX با اعداد واقعی و راست‌چین، و PDF از طریق صفحه چاپ بهینه. فیلترهای فعال مدیر در خروجی لحاظ می‌شوند.

## ۹. پنل مدیریت

`مدیریت قیمت خودرو` شامل: داشبورد، خودروها، آخرین قیمت‌ها، تاریخچه قیمت، گزارش‌ها، منابع اطلاعات، همگام‌سازی، تنظیمات. همه اعداد از دیتابیس واقعی محاسبه می‌شوند.
