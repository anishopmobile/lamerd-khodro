# طراحی موبایل‌فرست

## ۱. قاعده پایه

CSS سایت به‌صورت **موبایل‌فرست واقعی** نوشته شده است: هر فایل پایه، طرح ۳۲۰ پیکسل را توصیف می‌کند و لایه `responsive.css` فقط با `@media (min-width)` قابلیت اضافه می‌کند. هیچ قاعده `max-width` در پروژه وجود ندارد.

ترتیب بارگذاری:

1. `tokens.css` — متغیرهای رنگ، فاصله، تایپوگرافی، سایه
2. `base.css` — بازنشانی، تایپوگرافی، فوکوس، اسکیپ‌لینک
3. `layout.css` — پوسته، هدر، ناوبری، فوتر، شبکه‌ها، سکشن‌ها
4. `components.css` — کارت‌ها، جدول قیمت، فیلترها، مقایسه، نمودار
5. `pages.css` — صفحات اختصاصی (قیمت، برند، خودرو، مقایسه ۴۰۴)
6. `responsive.css` — لایه افزودنی؛ تنها فایل دارای media query

### استثنای مستند

دو کلاس (`.lk-header__cta` که `.lk-btn` هم دارد و `.lk-topbar__end`) در ابتدای `responsive.css` بدون media query مخفی می‌شوند، چون کلاس کامپوننت در فایل بعدی برنده specificity می‌شد. این دو قاعده «پایه موبایل» هستند و در ۶۰۰/۹۰۰ پیکسل بازگردانده می‌شوند.

## ۳. الگوهای تکرارشونده

- **جدول ↔ کارت**: `.lk-table-wrap` در پایه `display:none` و `.lk-price-cards` فعال است؛ در ۹۰۰ برعکس. هر دو از یک ردیف داده ساخته می‌شوند تا محتوا یکی بماند.
- **ناوبری**: `<nav>` در پایه پنهان و در ۹۰۰ نمایان؛ `#lk-menu-toggle` دراور را باز می‌کند (`aria-expanded`, `aria-controls`, بستن با `Esc`).
- **شبکه‌ها**: همه با `minmax(0, 1fr)` تا محتوای طولانی فارسی ستون را نشکند.
- **تصاویر**: `aspect-ratio` ثابت + `object-fit: cover`؛ پلیس‌هولدر بدون تصویر، آیکون و برند نشان می‌دهد.
- **نمودار**: ارتفاع پایه ۲۶۰px، در ۷۶۸ به ۳۰۰px؛ Chart.js با `maintainAspectRatio:false`.
- **لمس**: حداقل ۴۲×۴۲ برای دکمه‌های آیکونی، فاصله ۸px بین اهداف.

## ۴. راست‌به‌چپ

- `dir="rtl"` روی `<html>`، `lang="fa-IR"`.
- فقط Logical Properties: `margin-inline`, `padding-inline`, `inset-inline`, `border-inline-end`, `text-align:start`.
- هیچ `float:right` یا `left:` فیزیکی در CSS نیست.
- آیکون‌های جهت‌دار (فلش، بردکرامب) با `transform: scaleX(-1)` یا SVG آینه‌شده.
- جدول مقایسه از سمت راست شروع می‌شود و ستون اول چسبان است.

## ۵. روش تأیید

بازبینی روی این عرض‌ها انجام شد: ۳۲۰، ۳۶۰، ۳۹۰، ۴۸۰، ۶۰۰، ۷۶۸، ۹۰۰، ۱۰۲۴، ۱۲۸۰، ۱۴۴۰، ۱۹۲۰.

برای هر عرض:

1. اندازه‌گیری `document.documentElement.scrollWidth - innerWidth` باید صفر یا کمتر باشد (بدون اسکرول افقی).
2. بررسی `gridTemplateColumns` و `display` عناصر کلیدی (`.lk-nav`, `.lk-table-wrap`, `.lk-price-cards`, `.lk-stats`, `.lk-hero__grid`).
3. بازبینی چشمی هدر، هیرو، کارت‌ها، فیلترها، فوتر.
4. بررسی کنسول مرورگر برای خطای JS/CSS.

نتیجه فعلی: در ۳۶۰ پیکسل ناوبری پنهان، همبرگر فعال، جدول پنهان و کارت‌ها یک‌ستونه؛ اسکرول افقی صفر. در ۱۴۴۰ شبکه ۴ ستونه، اخبار ۳ ستونه، هیرو دو ستونه و جدول فعال است.

## ۶. نکات نگه‌داری

- مقدار جدید را اول در پایه بنویسید، بعد در نزدیک‌ترین `min-width` بازگردانید؛ هرگز `max-width` اضافه نکنید.
- اگر قاعده‌ای در `responsive.css` بدون media query نوشته‌اید، دلیلش را در همان‌جا کامنت کنید (مثل استثنای هدر).
- قبل از افزودن `!important`، specificity را بررسی کنید. در این پروژه فقط موارد فنی از آن استفاده می‌کنند: `.screen-reader-text`، سبک چاپ و `canvas` نمودار.
- فونت‌ها از `assets/fonts` با `font-display: swap` بارگذاری می‌شوند و هیچ درخواست خارجی ندارند.
