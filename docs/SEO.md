# SEO

## ۱. ساختار URL

| نوع | نمونه |
| --- | --- |
| خانه | `/` |
| قیمت روز | `/prices/` |
| خودرو | `/vehicles/{نام-فارسی-خودرو}/` |
| آرشیو خودروها | `/vehicles/` |
| برند | `/brand/{اسلاگ-برند}/` |
| مقایسه | `/compare/?ids=120,109` |
| برندها | `/brands/` |
| نوشته | `/{نام-نوشته}/` |

پیوند یکتا روی `/%postname%/` تنظیم شده و اسلاگ‌ها فارسی و خوانا هستند. ساختار صفحه‌های تکراری ساخته نشده: «بانک اطلاعات خودرو» همان آرشیو CPT است، نه صفحه‌ای جداگانه با محتوای کپی.

## ۲. عنوان و توضیح

`inc/seo.php` روی `wp_head` این موارد را تولید می‌کند:

- `<title>` اختصاصی برای خانه (نام سایت + ارزش پیشنهادی)، آرشیو، برند، خودرو و نوشته.
- `meta description` از خلاصه/توضیح خودرو یا نوشته، با برش امن و بدون HTML.
- `og:title`, `og:description`, `og:url`, `og:type`, `og:image` و `og:locale=fa_IR`.
- `canonical` مطلق برای صفحه اصلی، تک‌نوشته/خودرو، تاکسونومی، آرشیو CPT و وبلاگ؛ در جستجو چاپ نمی‌شود.
- `wp_robots`: نتیجه جستجو، ۴۰۴ و هر فهرست صفحه‌بندی‌شده یا فیلترشده (`page/paged`, `brand`, `sort`, `search`) با `noindex,follow` علامت می‌خورند تا محتوای تکراری فهرست‌ها ایندکس نشود.

## ۳. داده ساختاریافته

JSON-LD فقط برای موجودیت‌هایی که داده کامل دارند:

- `Organization` (نام، لوگو، نشانی سایت) در همه صفحات
- `WebSite` با `potentialAction` جستجو
- `BreadcrumbList` در صفحات داخلی
- `Article` در نوشته‌ها با `datePublished`, `dateModified`, `author`, `publisher`

**عمداً** از `Vehicle`/`Product` استفاده نشده است: تا وقتی مشخصات کامل (موتور، گیربکس، مصرف) برای همه خودروها ثبت نشود، این اسکیما ناقص و گمراه‌کننده می‌شود. وقتی فیلدها کامل شدند، افزودن آن در `inc/seo.php` یک تغییر محدود است.

## ۴. محتوای قابل ایندکس

- هر خودرو صفحه مستقل با عنوان، برند، مشخصات و قیمت دارد.
- هر برند صفحه فهرست با توضیح کوتاه دارد.
- قیمت‌ها با `time` و تاریخ شمسی قابل خواندن نمایش داده می‌شوند.
- منبع داده در هر صفحه نام برده می‌شود (اعتماد و شفافیت، بدون محتوای تکراری).

## ۵. سرعت و Core Web Vitals

- فونت وزیرمتن با `preload` و `font-display: swap`؛ بدون درخواست به Google.
- CSS در پنج فایل کوچک با ترتیب ثابت؛ JS با `defer` و بارگذاری شرطی.
- Chart.js فقط در صفحه خودرو بارگذاری می‌شود.
- تصاویر با `width`/`height` و `loading="lazy"` (به‌جز تصویر بالای صفحه).
- بدون jQuery در فرانت (jQuery فقط در پنل مدیریت برای سازگاری با وردپرس).

## ۶. کارهای پس از انتشار

1. اتصال به Google Search Console و ثبت sitemap وردپرس (`/wp-sitemap.xml`).
2. حذف `noindex` از محیط staging قبل از انتشار.
3. بررسی صفحات ۴۰۴ و ریدایرکت مسیرهای قدیمی در صورت مهاجرت.
4. افزودن `Vehicle` schema پس از تکمیل مشخصات.
5. بازبینی عنوان‌ها در گزارش Search Console پس از ۴ هفته.
