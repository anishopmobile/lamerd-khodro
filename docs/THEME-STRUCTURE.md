# ساختار قالب

قالب `lamerd-khodro` بدون وابستگی به صفحه‌ساز و بدون فریم‌ورک ساخته شده است. هیچ تمپلیت فرزند یا کتابخانه خارجی بارگذاری نمی‌شود.

## ۱. فایل‌های ریشه

| فایل | وظیفه |
| --- | --- |
| `style.css` | هدر قالب (نام، نسخه، توضیح)؛ استایل واقعی در `assets/css` است |
| `functions.php` | تعریف ثابت‌ها، بارگذاری `inc/*` به ترتیب وابستگی |
| `header.php` | `<!doctype>`, `dir="rtl"`, تاپ‌بار، لوگو، جستجوی زنده هدر، دکمه‌های مقایسه/منو، نوار تیره برندها با مگامنوی خودروهای هر برند، منوی کشویی موبایل |
| `footer.php` | ستون‌های فوتر، منوی فوتر، لینک منبع، اسکریپت‌ها، `wp_footer()` |
| `front-page.php` | ترکیب سکشن‌های خانه؛ بلوک آگهی‌های فروش بین هیرو و قیمت روز، سپس سکشن‌های Customizer |
| `index.php` | فهرست پیش‌فرض نوشته‌ها |
| `archive.php` | آرشیو نوشته‌ها و دسته‌ها |
| `single.php` | تک‌نوشته با بردکرامب، متا، محتوای مرتبط |
| `page.php` | صفحه ساده |
| `search.php` | نتایج جستجو با حالت خالی |
| `404.php` | صفحه ۴۰۴ با مسیرهای پیشنهادی |
| `archive-lk_vehicle.php` | بانک اطلاعات خودرو (آرشیو CPT) با فیلتر برند |
| `single-lk_vehicle.php` | صفحه خودرو: هیرو، مشخصات، پنل قیمت، نمودار، خودروهای مشابه |
| `taxonomy-lk_brand.php` | صفحه برند با فهرست خودروها و توضیح |
| `archive-lk_listing.php` | آگهی‌های فروش: هوک `lk_listings_before` (بخش طرح‌های ثبت‌نام)، بخش فروش ویژه، شبکه آگهی‌ها، صفحه‌بندی، حالت خالی |
| `single-lk_listing.php` | آگهی فروش: هیرو قیمت/تماس، تایمر ویژه، تصویر، مشخصات، آگهی‌های دیگر |

## ۲. `inc/`

| فایل | وظیفه |
| --- | --- |
| `setup.php` | `add_theme_support`ها، جایگاه منو (`primary`, `footer`)، ساخت یک‌باره صفحات/منوها/دسته‌ها/مقالات راهنما، fallback منو (آگاه به location) |
| `enqueue.php` | بارگذاری شرطی شش فایل CSS و هفت فایل JS، `preload` فونت، `LK` localize (`restUrl`, `ajaxUrl`, `nonce`, `strings`) |
| `template-tags.php` | قرارداد نمایش: `lk_opt`, `lk_money`, `lk_change_badge`, `lk_section_head`, `lk_breadcrumb`, `lk_update_note`, `lk_pagination`, `lk_source_link`, `lk_toggle`, `lk_page_url` |
| `icons.php` | اسپرایت SVG درون‌خطی و تابع `lk_icon()` |
| `mega-menu.php` | داده مگامنوی هدر: `lk_mega_brands()` (برندهای پرمدل + ۸ خودرو با تصویر)، `lk_mega_brand_tabs()` (تب‌های زیربرند از فرزندان `lk_brand`)، `lk_mega_items()`، `lk_mega_cards()`، `lk_mega_vehicle_image()`، `lk_mega_placeholder()` و `lk_mega_all_brands()` |
| `ajax.php` | فیلتر قیمت و مقایسه سمت سرور، تبدیل ورودی میلیون‌تومان، صفحه‌بندی قابل استفاده بدون JS، جستجوی زنده گروه‌بندی‌شده (`lk_live_search`: خودرو، برند، آگهی) |
| `seo.php` | عنوان، description، Open Graph، canonical، `wp_robots`، JSON-LD |
| `admin.php` | پنل Customizer «لامرد خودرو» و `lk_theme_defaults()` |

## ۳. `page-templates/`

| فایل | قالب صفحه |
| --- | --- |
| `page-prices.php` | «قیمت روز خودرو» — فیلترها + جدول دسکتاپ + کارت موبایل + صفحه‌بندی |
| `page-compare.php` | «مقایسه خودرو» — چهار اسلات، انتخاب با جستجو، جدول مقایسه |
| `page-brands.php` | «برندها» — کاشی برندها با تعداد خودرو |

## ۴. `template-parts/`

```
home/      hero, sale-listings, price-board, brands, latest, movers, compare-cta, news, reviews, sales
price/     table, row, card            (جدول و کارت از یک داده)
vehicle/   card, price-panel           (کارت خودرو، پنل قیمت تک‌خودرو)
news/      card                        (کارت مقاله با تصویر یا پلیس‌هولدر)
compare/   table                       (جدول مقایسه چندخودرو)
listing/   card                        (کارت آگهی با برچسب و تایمر فروش ویژه)
components/ page-hero, empty-data      (هدر صفحات داخلی، حالت بدون داده)
```

هیچ template-part داده را مستقیم از `$wpdb` نمی‌خواند؛ همه از توابع `lk_*` یا آرگومان‌های `get_template_part` می‌آیند.

## ۵. `assets/`

### CSS (ترتیب بارگذاری ثابت)

| فایل | محتوا |
| --- | --- |
| `tokens.css` | متغیرهای رنگ/فاصله/شعاع/سایه، `@font-face` وزیرمتن |
| `base.css` | بازنشانی، تایپوگرافی، لینک، فوکوس، `.screen-reader-text`, `.lk-skip` |
| `layout.css` | کانتینر، تاپ‌بار، هدر، ناوبری، دراور، فوتر، شبکه‌ها، سکشن‌ها |
| `components.css` | دکمه‌ها، کارت‌ها، جدول قیمت، فیلترها، بج تغییر، نمودار، مقایسه، فوتر |
| `pages.css` | هیرو صفحه اصلی، هیروی خودرو، صفحه قیمت، برند، مقایسه، ۴۰۴، سبک چاپ |
| `responsive.css` | تنها فایل دارای media query؛ افزودن قابلیت با `min-width` |

### JS

| فایل | بارگذاری | وظیفه |
| --- | --- | --- |
| `app.js` | همه صفحات | دراور موبایل، هدر چسبان، سبد مقایسه در `localStorage` |
| `search.js` | همه صفحات | جستجوی زنده هدر: سه گروه نتیجه، تصویر/مونوگرام، ناوبری با کیبورد و شیت جستجوی موبایل |
| `mega-menu.js` | همه صفحات | مگامنوی برندها: باز شدن با هاور/کلیک، فقط یک پنل باز، Escape و بازگشت فوکوس؛ تب‌های زیربرند با ناوبری کیبورد |
| `price-table.js` | صفحه قیمت | فیلتر AJAX، مرتب‌سازی، صفحه‌بندی، همگام‌سازی URL |

### فونت

`assets/fonts/` شامل وزن‌های وزیرمتن به‌صورت `woff2` است. هیچ درخواستی به Google Fonts یا CDN وجود ندارد.

## ۶. قواعد نگه‌داری

- داده فقط از `lk_*`؛ اگر تابعی کم است، به Core اضافه شود نه به قالب.
- استایل جدید در فایل موضوعی خودش، با Logical Properties.
- هر بخش خانه باید بدون داده هم قابل رندر باشد (`empty-data.php`).
- متن‌های UI فارسی و قابل ترجمه با `esc_html_e` نگه‌داری می‌شوند.
- برای افزودن صفحه جدید: فایل در `page-templates/` + ثبت در `setup.php` + لینک در منو.
