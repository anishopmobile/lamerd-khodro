# نصب و راه‌اندازی

## ۱. پیش‌نیازها

| مورد | حداقل | تست‌شده |
| --- | --- | --- |
| PHP | 8.1 | 8.3.30 |
| MySQL / MariaDB | 5.7 / 10.3 | MariaDB لاراگون |
| وردپرس | 6.5 | 7.1 |
| افزونه وردپرس | هیچ افزونه اجباری نیست | — |
| دسترسی | نوشتن در `wp-content` و ساخت جدول | — |

پروژه بدون Composer و npm کار می‌کند؛ فایل‌های ساخته‌شده (CSS/JS/فونت) در مخزن هستند.

## ۲. قرار دادن فایل‌ها

```
wp-content/
├── themes/lamerd-khodro/
└── plugins/
    ├── lamerd-khodro-core/
    └── lamerd-khodro-price-engine/
tools/lk-dev.php          (فقط توسعه؛ در تولید لازم نیست)
```

## ۳. ترتیب فعال‌سازی

1. **افزونه Core** را فعال کنید. CPT `lk_vehicle`، تاکسونومی `lk_brand` و جداول `lkp_*` ساخته می‌شوند.
2. **افزونه Price Engine** را فعال کنید. کران دریافت روزانه، جداول تاریخچه و گزارش ثبت می‌شوند.
3. **قالب lamerd-khodro** را فعال کنید. در اولین بار:
   - صفحات اصلی (قیمت، مقایسه، برندها، درباره، تماس، قوانین) ساخته می‌شوند،
   - منوی اصلی و منوی فوتر ساخته و به جایگاه‌ها وصل می‌شوند،
   - صفحه اصلی روی صفحه «خانه» تنظیم می‌شود،
   - دسته‌های اخبار و سه مقاله راهنما درج می‌شوند،
   - گزینه `lk_content_seeded` ثبت می‌شود تا اجرای دوباره محتوای تکراری نسازد.

اگر ترتیب را برعکس کردید، مشکلی پیش نمی‌آید؛ فقط در صورت نبود وابستگی، قالب حالت خالی نشان می‌دهد و بعد از فعال‌سازی Core همه‌چیز پر می‌شود.

## ۴. پیوندهای یکتا

«تنظیمات ← پیوندهای یکتا» را روی **نام نوشته** بگذارید و ذخیره کنید. اگر `.htaccess` قابل نوشتن نیست، این بلوک را دستی اضافه کنید:

```apache
# BEGIN WordPress
<IfModule mod_rewrite.c>
RewriteEngine On
RewriteBase /lamerd-khodro/
RewriteRule ^index\.php$ - [L]
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule . /lamerd-khodro/index.php [L]
</IfModule>
# END WordPress
```

## ۵. اولین دریافت قیمت

از پنل: **مدیریت قیمت خودرو ← همگام‌سازی ← دریافت اطلاعات**. یا از خط فرمان:

```bash
php tools/lk-dev.php status     # وضعیت جداول، تعداد رکوردها، آخرین همگام‌سازی
php tools/lk-dev.php sync       # اجرای یک دریافت کامل
php tools/lk-dev.php errors     # خطاهای اخیر موتور قیمت
```

پس از اجرا انتظار می‌رود:

- تعداد خودروها و قیمت‌ها افزایش یابد،
- هر خودرو یک ردیف تاریخچه با تاریخ امروز داشته باشد،
- صفحه «قیمت روز» و صفحه یک خودرو داده واقعی نشان دهند،
- نمودار تک‌خودرو پیام «داده کافی نیست» بدهد (طبیعی است؛ تاریخچه یک‌روزه است).

## ۶. زمان‌بندی

کران وردپرس زمان‌بندی اختصاصی افزونه را اجرا می‌کند؛ بازه پیش‌فرض ۶۰ دقیقه است و از «تنظیمات» موتور قیمت قابل تغییر است (فهرست بازه‌های مجاز در `LKPE_Cron::allowed_intervals()`). برای سایت‌های کم‌بازدید، کران واقعی سیستم را جایگزین کنید:

```
*/15 * * * * curl -s https://example.com/wp-cron.php?doing_wp_cron >/dev/null 2>&1
```

## ۷. بررسی پس از نصب

## ۸. عیب‌یابی

| نشانه | علت احتمالی | راه‌حل |
| --- | --- | --- |
| همه لینک‌های داخلی 404 | پیوند یکتا یا `.htaccess` | بازنویسی را ذخیره و فایل را بررسی کنید |
| «قیمتی ثبت نشده» برای همه | همگام‌سازی اجرا نشده یا منبع در دسترس نیست | `status` و `errors` را ببینید؛ سپس `sync` |
| درصد تغییر «—» | فقط یک روز تاریخچه | طبیعی است؛ با گذشت روزها پر می‌شود |
| نمودار خالی | کمتر از دو نقطه داده | طبیعی است؛ پیام `insufficient` |
| دریافت متوقف با 429 | سقف ۱۲۰ درخواست در دقیقه | صبر کنید؛ موتور با backoff ادامه می‌دهد |
| رکورد زیاد `suspect` | تغییر ساختار منبع | گزارش اعتبارسنجی را بررسی و نگاشت را به‌روز کنید |

## ۹. پشتیبان‌گیری و به‌روزرسانی

- پیش از هر به‌روزرسانی از جداول `lkp_*` و `wp_options` بکاپ بگیرید؛ تاریخچه قیمت قابل بازسازی نیست.
- به‌روزرسانی شامل جایگزینی پوشه قالب/افزونه‌ها و اجرای `php tools/lk-dev.php status` است.
- حذف افزونه Core داده‌ها را پاک نمی‌کند مگر گزینه حذف کامل در تنظیمات انتخاب شود؛ با احتیاط عمل کنید.
