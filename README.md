# لامرد خودرو

پلتفرم قیمت و اطلاعات خودرو به زبان فارسی: قالب اختصاصی وردپرس + دو افزونه مستقل برای دامنه و موتور قیمت. همه قیمت‌هایی که در سایت نمایش داده می‌شوند از دیتابیس داخلی خوانده می‌شوند؛ API بیرونی فقط برای **دریافت** داده و ذخیره‌سازی در تاریخچه استفاده می‌شود.

- آدرس نصب نمونه: `http://localhost/lamerd-khodro`
- وردپرس ۶٫۸+ (تست‌شده روی ۷٫۱)، PHP 8٫1+ (تست‌شده روی 8.3.30)، MySQL 5.7+/MariaDB
- بدون صفحه‌ساز، بدون فریم‌ورک CSS، بدون فونت یا اسکریپت خارجی

## اجزای پروژه

| جزء | مسیر | نقش |
| --- | --- | --- |
| قالب | `wp-content/themes/lamerd-khodro` | تنها لایه نمایش؛ RTL و موبایل‌فرست، فونت وزیرمتن محلی |
| افزونه هسته | `wp-content/plugins/lamerd-khodro-core` | CPT، تاکسونومی، جدول‌ها، پرس‌وجو، REST و API‌های `lk_*` |
| موتور قیمت | `wp-content/plugins/lamerd-khodro-price-engine` | دریافت از کافه خودرو، اعتبارسنجی، ذخیره تاریخچه، گزارش، خروجی، پنل مدیریت |
| ابزار توسعه | `tools/lk-dev.php` | دستورات CLI برای وضعیت، فعال‌سازی، همگام‌سازی و بررسی خطاها |

جهت وابستگی یک‌طرفه است: قالب ← `lk_*` هسته ← مخزن قیمت. قالب هیچ‌گاه مستقیم به جدول یا API بیرونی دست نمی‌زند.

## نصب سریع

1. وردپرس را در ریشه سایت نصب کنید (MySQL با پیشوند دلخواه).
2. پوشه‌های قالب و دو افزونه را در جای خود قرار دهید.
3. افزونه‌ها را فعال کنید؛ جداول در هوک فعال‌سازی ساخته می‌شوند.
4. قالب «لامرد خودرو» را فعال کنید؛ صفحات، منوی اصلی، منوی فوتر، دسته‌ها و مقالات راهنما یک‌بار ساخته می‌شوند.
5. پیوندهای یکتا را روی «نام نوشته» بگذارید.
6. از «مدیریت قیمت خودرو ← همگام‌سازی» اولین دریافت را اجرا کنید.

## منبع داده

نام و لینک منبع در تمام صفحات قیمت ذکر می‌شود: **کافه خودرو**. داده‌های این نصب صرفاً از همان منبع رسمی دریافت و در دیتابیس داخلی نگه‌داری می‌شوند؛ هیچ عدد یا تاریخچه‌ای به‌صورت نمونه‌سازی تولید نمی‌شود. محدودیت درخواست (۱۲۰ درخواست در دقیقه) و بازآزمایی برای 429/5xx/Timeout در موتور قیمت اعمال شده است.
